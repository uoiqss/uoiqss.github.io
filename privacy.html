隱私權政策

生效日期：2026 年 10 月 7 日

適用範圍

本政策適用於「uoiqss 個人自動化工具」（以下稱本工具）。本工具僅供擁有者本人使用。

存取的資料

經使用者透過 Google OAuth 授權後，本工具可能存取：Gmail 郵件、Google 日曆事件、Google 雲端硬碟檔案，以及帳戶基本資料（電子郵件地址、名稱）。實際範圍以授權畫面顯示的權限為準。

資料用途

資料僅用於替使用者本人讀取、建立或整理其行程、郵件與文件，不作其他用途。

分享與販售

本工具不販售、不出租、不分享任何使用者資料給第三方，也不將資料用於廣告。

Google API 使用聲明

本工具使用及傳輸自 Google API 取得的資訊，遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

儲存與保護

授權憑證僅存放於擁有者控制的環境，不公開。本工具不另行建立使用者資料庫。

撤銷授權

使用者可隨時於 Google 帳戶第三方存取權 頁面撤銷本工具的授權。
